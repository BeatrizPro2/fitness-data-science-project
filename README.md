# Fitness Data Science Dashboard 

A personal fitness analytics dashboard built with Streamlit. It turns your
Strong app workout exports and Fitdays body-composition screenshots into
visual insights, and generates goal-aware training recommendations using a
local AI model (Ollama).


## Features

- **Training dashboard** — total training days, volume over time, and volume-by-day charts from your Strong CSV export.
- **Exercise table** — every exercise with its type (Weighted / Bodyweight / Cardio), estimated 1-rep-max, best weight, and training frequency (days, sets, reps). Impossible weight entries are automatically filtered.
- **Cardio table** — distance and time for cardio exercises (running, elliptical, stair machine).
- **Body composition** — reads Fitdays result screenshots via OCR and displays weight, body fat, muscle mass, and other metrics.
- **AI recommendations** — goal-aware strengths and focus areas generated by a local Ollama model, citing your actual numbers. Falls back to rule-based tips if Ollama is not running.

## Setup

1. **Create and activate a virtual environment**
```
python -m venv .venv
.venv\Scripts\activate      # Windows
source .venv/bin/activate   # macOS / Linux
```
2. **Install Python dependencies**
```
pip install -r app/requirements.txt
```

3. **Install Tesseract** (required for reading Fitdays screenshots)
   - Windows: install from the UB-Mannheim Tesseract build
   - macOS: `brew install tesseract`
   - Linux: `apt install tesseract-ocr`

4. **Install Ollama for AI recommendations**
   - Install Ollama from ollama.com
   - Pull a model: `ollama pull qwen2.5:3b`
   - If Ollama is not running, the app automatically uses rule-based recommendations instead.

## Running the app
```
streamlit run app/app.py
```

Then open the local URL shown (usually http://localhost:8501).

## How to use

1. Export your workout data from the Strong app as a CSV.
2. (Optional) Take a screenshot of your Fitdays results screen.
3. In the app, pick your goal, upload your Strong CSV and any Fitdays screenshots, and click **Build dashboard**.

## Notes

- Body-composition tracking reads from Fitdays screenshots; upload one per session.
- AI recommendations are general fitness guidance, not medical or nutritional advice.
- All uploaded data is processed locally and is not stored or sent anywhere.

## Project structure
